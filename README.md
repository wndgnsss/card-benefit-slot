# 카드 혜택 추천기

고객에게는 **소비 행태에 맞는 카드 혜택 영역 Top-K**를 추천하고, 카드사에는 그 추천을 모아 **상품 설계의 입력값**(영역 수요·영역 조합·예상 혜택비용)으로 보여주는 기획 프로토타입입니다.
흐름: 고객 입력 → 혜택 영역 추천 → 추천 결과 집계 → 상품안 수치화 → 수익성 검토의 입력값
KAIST DFMBA 「인공지능과 추천시스템(BAF670)」 중간보고서(기말 프로젝트 기획안)의 부속 자료입니다.

- 실행: 이 저장소의 GitHub Pages 주소에서 바로 열립니다. 또는 `index.html`을 내려받아 브라우저로 열면 됩니다(설치 불필요).

## 무엇을 보여주나
**고객 화면(기본):** 결제 수단(신용·체크 비중), 한 달 사용액, 좋아하는 혜택 형태, 자주 쓰는 곳과 곳별 월 이용 횟수·1회 금액을 버튼으로 고르면 필요한 혜택 영역 5개와 계산 근거(예: 월 4회 × 1회 3만 원 × 할인 5% = 6,000원)를 보여줍니다. 고르지 않은 곳은 「함께 고려해 볼 곳」으로 제안합니다.

**관리자 화면:** 아래 추천 방식 비교와 상품 설계 집계.

같은 입력에 대해 세 가지 추천 방식을 나란히 비교합니다.

| 방식 | 수업 주차 | 내용 |
|---|---|---|
| 인기 기반 | 3주차 | 전체 사용자의 영역 이용률 순 |
| 규칙 기반 | 3주차 | 카드 비교 플랫폼의 카테고리 필터 방식: 체크한 영역 우선, 나머지 인기순 |
| 하이브리드 | 4·5주차 | 점수 = β·Item-based CF + (1−β)·(설문 + 콘텐츠 기반), β = n/(n+2), n = 이용 개월 수 |

상품 설계 탭(카드사): 합성 고객 400명에게 신규 고객 추천을 돌려 영역별 수요 상위 10개, 자주 나오는 영역 조합 상위 5개, 상품안(수요 상위 K개 영역)의 고객당 월 예상 혜택비용과 가정 수수료수익을 계산합니다. 모든 금액은 가정값입니다.

추가 기능: 혜택 재정렬(관심 점수 × 지출 × 할인율, 영역 한도 상한), 할인율 균등/차등 시나리오, 전월실적 미달 경고, 수락·제외 피드백 로그.

## 분류 기준표 v1
하나카드 원더카드2.0의 서비스 영역 57개를 참고해 재구성했습니다.
- 결제 채널·범위 항목 5개(국내외 가맹점, 간편결제, 바코드 결제, 해외, 무이자할부)는 아이템이 아니라 거래 속성으로 분리
- 같은 업종의 가맹점별 영역은 통합(예: 백화점 3사 → 백화점, 통신 3사 → 통신요금)
- 결과: 업종 아이템 41개, 대분류 7개

## 데이터
- 페이지 안에서 생성한 합성 사용자 400명 × 6개월 영역별 이용 기록(페르소나 6종 + 개인 노이즈, 시드 고정)
- 실제 고객·회사 데이터는 사용하지 않았습니다.
- 생성 규칙을 직접 정했기 때문에 성능 수치는 의미가 없어 표시하지 않습니다. 성능 평가는 기말에 공개 합성 거래 데이터(IBM Credit Card Transactions, Apache-2.0)로 수행할 계획입니다.

## 기말 계획
- 공개 합성 거래 데이터의 업종 코드(MCC)를 분류 기준표에 매핑해 사용자 × 영역 × 월 행렬 구성
- 시간 분할 평가(과거 6개월 학습 → 다음 달), HitRate@K · NDCG@K
- Python(pandas · scikit-learn · PyTorch) 구현, 행렬분해·NCF와 비교
